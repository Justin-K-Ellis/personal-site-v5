An educational app for reading and remembering English. Authenticated users can read short passage and answer comprehension questions, have their answers automatically scored, and review their stats.

## Features

- Curated passages from a variety of [CEFR](https://en.wikipedia.org/wiki/Common_European_Framework_of_Reference_for_Languages) bands, presented in assending order, with comprehension question
- English and Japanese UI
- Reading/scoring history persisted for authenticated users
- User dashboard

## Stack

- Main application language: TypeScript
- Framework: Next.js (app router)
- Database: PostgreSQL
- ORM: Drizzle
- Internationalization: next-intl
- Validation: Zod
- CSS styling: Tailwind CSS with shadcn/ui
