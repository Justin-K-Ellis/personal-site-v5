An app that indexes events from around Japan and lets users find them with a rich search interface, save interesting events, and anonymously share them.

## Features

- Search by:
  - Location (prefecture or distance from you)
  - Keywords
  - Event type
  - Start and/or end date
  - Event type
- Save events to your personal timeline
- Anonymously share event lists
